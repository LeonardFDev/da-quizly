# Quizly

[🇩🇪 Deutsche Version](README_DE.MD)

## Description

This project was developed as a learning project to gain practical experience in developing a web application using Django and the Django REST Framework. The focus is on implementing a backend with a REST API through which a provided frontend communicates with the backend. Among other things, HTTP requests are processed and protected endpoints are secured using JWT-based authentication. Access and refresh tokens are used for this purpose and are transmitted and managed between the frontend and backend via cookies.

In addition, an audio file is downloaded and processed locally. The audio file is first transcribed into text using a speech-to-text application. The resulting text is then passed to an AI along with a predefined prompt. The response generated by the AI is subsequently processed by the backend and prepared for further use.

# Authentication

The API uses JWT-based authentication with the Django REST Framework. Access and refresh tokens are used for authentication and are transmitted between the frontend and backend via cookies.

JWT components used:

```text
Access Token
Refresh Token
```

## Token Creation

When a user logs in, an access token and a refresh token are generated. These tokens are stored in cookies and are used for authentication and renewing the authentication session.

## Authenticated Requests

Protected API requests are authenticated using the access token. The token is transmitted to the backend via a cookie and its validity is verified by the backend.

If the access token expires, the refresh token can be used to request a new access token.

Authentication is therefore handled through cookies transmitted between the frontend and backend rather than through an Authorization header.

# API Endpoints

The application provides the following API endpoints:

| No. | Method   | Endpoint               | Name            | Description                                            |
| --- | -------- | ---------------------- | --------------- | ------------------------------------------------------ |
| 1   | POST     | `api/register/`        | registration    | Register user                                          |
| 2   | POST     | `api/login/`           | login           | Log in user                                            |
| 3   | POST     | `api/logout/`          | logout          | Log out user                                           |
| 4   | POST     | `api/token/refresh/`   | token_refresh   | requested a new access token using the refresh token   |
| 5   | POST     | `api/quizzes/`         | quiz-list       | Create a new quiz with its questions                   |
| 6   | GET      | `api/quizzes/`         | quiz-list       | Retrieves all quizzes with their questions             |
| 7   | GET      | `api/quizzes/<pk>/`    | quiz-detail     | Returns a single quiz with its questions               | 
| 8   | PATCH    | `api/quizzes/<pk>/`    | quiz-detail     | Updates an existing quiz                               |
| 9   | DELETE   | `api/quizzes/<pk>/`    | quiz-detail     | Delete a quiz with its questions                       |
